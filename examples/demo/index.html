legal-drafter로 카테고리형 법률 문서를 초안부터 산출물까지 생성합니다.

카테고리와 서브타입을 고르고, 필요한 고유명사와 사실관계를 입력한 뒤, 로컬 법령 인덱스에서 직접 조문을 선택하면 A4 인쇄형 HTML, PDF, PNG 미리보기까지 한 번에 확인할 수 있습니다.

수동 법률 선택 카테고리별 추천 범위를 바탕으로 조문을 직접 포함·제외합니다.
스펙 기반 폼 서브타입별 입력 필드가 동적으로 바뀌며 반복 그룹도 지원합니다.
최종 산출물 PDF 원본과 페이지별 PNG 미리보기를 함께 생성합니다.

사전 준비

1. 인덱스 준비
legal-drafter-index refresh --service-topic ECOMMERCE --rebuild
2. Ollama 실행
ollama serve와 사용할 모델을 먼저 준비합니다.
3. 렌더링 환경
PDF/PNG 산출에는 Playwright Chromium이 필요합니다.

문서 입력

카테고리, 서브타입, 필드값, 법률 선택 순서로 입력합니다. 절차 문서는 필수값 누락 시 최종 PDF/PNG 생성을 막습니다.

법령 검색

카테고리별 시드 키워드가 적용된 상태로 조문을 검색하고, 필요한 조문만 선택합니다.

검색 결과가 여기에 표시됩니다.

선택된 조문

생성 엔진은 여기서 선택한 법령 발췌만 인용합니다.

아직 선택된 조문이 없습니다.

LLM 응답과 PDF/PNG 렌더링 때문에 수십 초가 걸릴 수 있습니다.

결과

생성 결과 요약, 검토 포인트, 선택 인용, 최종 산출물 링크와 PNG 미리보기를 확인합니다.
